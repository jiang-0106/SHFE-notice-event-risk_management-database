# SHFE 市场研究助手 v0.18

v0.18 重点补齐 v0.17 的审计链条，并增加全品种数据完整性总表。研究边界不变：当前阶段只做公告、参数和市场数据的同步对应及历史异常描述，不预测收益方向，不输出交易建议。

## 本轮改进

- 三类官方接口逐工作日核验至 2026-10-05，最新有效交易日均为 2026-09-30。
- HTTP 404 单独标记为 `official_file_not_available`，不再与网络失败混为一类。
- `trade_parameter_market_alignment_daily` 重建至 2026-09-30，共 3,157 个参数交易日。
- `trade_parameter_settlement_reconciliation_daily` 重建至 2026-09-30，共 3,157 个参数交易日。
- 新增25个品种的 `product_data_completeness_dashboard`，展示日期覆盖、合约覆盖率、两来源保证金一致率、公告核验数量和研究可用状态。
- 新增行情参数对账、结算参数核对及参数来源差异汇总 CSV。

## 关键审计结果

- 行情与官方交易参数：3,016 日完全匹配，141 日保留键覆盖差异。
- 2026-09-11 至 2026-09-30 新增的13个交易日，行情与交易参数均为精确键匹配。
- 两类参数来源：1,785 日键与保证金均一致；85 日仅键覆盖不同；1,287 日存在保证金数值差异。
- 新增日期中有6日存在参数来源差异，涉及1,096个合约—字段差异记录。差异均原样保留，不自动选择某一来源覆盖另一来源。
- AO、BU 已具备人工核验公告记录；其余23个品种的市场与参数同步可用，但公告仍待人工核验。

## 完整性总表字段解释

- `trade_parameter_contract_coverage_pct`：2013-10-08以后行情合约能够匹配官方交易参数的比例。
- `settlement_contract_coverage_pct`：行情合约能够匹配每日结算参数的比例。
- `margin_agreement_pct`：两类官方参数来源都存在时，四项保证金字段完全一致的合约比例。
- `research_readiness_status`：区分“公告—参数—市场同步研究可用”“市场与参数同步可用，公告待核验”和“数据覆盖需复核”。
- `completeness_issues_cn`：列出公告缺失、日期覆盖不足、来源差异或接口失败等问题。

## 使用方法

双击输出目录中的 `启动研究助手.cmd`。数据库完整性总表及三类审计结果同时保存在 `exports` 文件夹中，可直接使用 Excel 打开。

“两类官方参数来源存在差异”不等于数据库错误。它表示交易参数文件和每日结算参数文件对同一合约的保证金字段不完全一致，需要结合字段定义、生效时点和公告进一步解释。
