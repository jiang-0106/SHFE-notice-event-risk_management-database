# SHFE 市场研究助手 v0.17

v0.17 是在 v0.16 功能基础上的数据完整性更新，不改变“只做同步对应和研究关注、不做收益方向预测、不生成交易指令”的研究边界。

## 本轮更新

- 官方期货日行情、每日结算参数和期货交易参数均逐日核验至 2026-10-02。
- 三类数据的最新有效交易日均为 2026-09-30；2026-10-01、2026-10-02 官方接口无可用日文件，按“已检查、无记录”保存，不作为漏采。
- 全品种市场、结算参数、交易参数同步数据库更新至 2026-09-30，并重新计算主力合约序列和公告—参数变更点对应层。
- 新鲜度判断不再只看自然日差，而是同时检查官方接口覆盖日期和未解决的网络/格式错误。节假日休市不会被误报为数据库过期。

## 核心结果

- 市场合约日记录：865,652 行。
- 市场品种日记录及主力日记录：各 73,494 行。
- 每日结算参数：706,348 行。
- 官方日度交易参数：669,737 行。
- 公告政策区间：21 条。
- 激烈或极端交易日：2,279 条。
- 品种研究快照：25 个品种。

## 使用方法

双击输出目录中的 `启动研究助手.cmd`，浏览器将打开本地研究页面。选择品种后可查看参数区间、市场历史强度、激烈交易日、参数变更、核验公告和指标文献。

“已核验至官方最新可用日”只说明采集程序已经检查到指定日期，不能等同于实时行情，也不能解释为适合交易。

## 可复现更新顺序

1. 运行 `scripts/download_shfe_incremental_v017.py`，逐日下载并验证三类官方文件。
2. 运行 `scripts/integrate_shfe_incremental_v017.py`，在不覆盖旧数据库的前提下生成增量基础库。
3. 运行公告参数变更点对应脚本，重新生成参数变化与公告核验表。
4. 运行 `scripts/build_market_research_assistant_v016.py`，通过 `--version`、`--artifact-tag` 和 `--build-date` 生成目标版本研究助手。

所有官方检查结果均保存在 `official_data_availability_check` 表中，便于区分有效交易日、休市无文件和真正的采集失败。
