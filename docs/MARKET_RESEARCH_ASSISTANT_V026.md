# SHFE 市场研究助手 v0.26

v0.26 继续完善三个核心功能的可操作性，不改变数据库的研究口径，也不新增收益方向预测或买卖建议。

## 1. 图表悬停解释

- 历史交易强度图：悬停显示日期、综合强度、级别和主力合约；
- 六指标分解图：悬停显示同一交易日的收益冲击、区间波动、成交量、成交额、持仓变化和非流动性历史分位；
- 参数变化图：悬停显示参数值、起止日期、适用范围和来源层。

悬停信息直接来自已加载的数据库记录，不增加新的推断。

## 2. 图表与明细导出

- 三张图均可一键导出 PNG，用于阶段汇报；
- 最近激烈交易日可按级别、起始日和结束日筛选；
- 当前筛选结果可导出带 UTF-8 BOM 的 CSV，便于 Excel 直接打开；
- 页面明确提示筛选范围为当前品种最近 30 条激烈或极端交易日记录，避免误解为全历史穷举。

## 3. AI接口核验

按照 OpenAI 官方文档重新核验：

- 当前默认模型仍为 `gpt-6-astra`；
- 继续使用 `POST /v1/responses`；
- 结构化输出继续放在 `text.format`；
- `store: false` 保持不变；
- 未配置 `OPENAI_API_KEY` 时，AI按钮和自动调用仍禁用，量化功能不受影响。

## 4. 研究边界

- 激烈日与公告、参数变化的邻近关系只作为同步核验线索，不自动解释为因果；
- 分位数表示相对该品种历史的位置，不是上涨或下跌概率；
- PNG 和 CSV 是当前页面证据的导出，不替代数据库完整性审计；
- 数据滞后时不得用AI或量化结果判断当前是否适合交易。
