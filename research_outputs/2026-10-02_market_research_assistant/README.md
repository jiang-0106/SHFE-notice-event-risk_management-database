# v0.16 market research assistant outputs

This review-sized folder accompanies the full derived SQLite database, which remains outside ordinary Git history.

## Files

- `notice_parameter_policy_intervals_v016.csv`: 21 AO/BU verified notice-parameter intervals.
- `product_research_snapshot_v016.csv`: one auditable research snapshot for each of 25 products.
- `intense_trading_days_v016.csv`: historical intense/extreme days under the documented composite rule.
- `indicator_literature_registry_v016.csv`: indicator formulas, sources and adaptation limits.
- `v016_build_summary.json`: database hash, counts and integrity result.
- `v016_validation_summary.json`: automated tests, API smoke test, browser UI check and the unrun live-AI test disclosure.

## Scope

The output is descriptive. It identifies historical abnormality and research attention, not return direction or trading suitability. The last complete market date is 2026-09-09, so the 2026-10-02 snapshot is explicitly stale and cannot support a current-market conclusion.
