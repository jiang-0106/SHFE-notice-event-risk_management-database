# v2.2 优化记录：正文完整性修复

执行日期：2026-08-20

## 优化目标

对 v2.1 中 `body_text` 为空的 94 篇公告进行逐条根因分析和公开源回补，不覆盖 v2.1 正式版。

## 根因

- 6 篇：正文以 GIF/JPG 图片形式嵌入详情页，原下载器未把正文图片作为附件保存。
- 88 篇：正文使用 JavaScript 跳转到旧版详情页或会员站文件，原下载器未跟随该类跳转。
- 本地详情 HTML 缺失：0 篇。

因此，这 94 篇不是普通 CSS 选择器漏解析，而是正文资源发现逻辑不完整。

## 回补结果

| 指标 | 数量 |
|---|---:|
| 尝试回补 | 94 |
| 成功取得源文件 | 54 |
| 源端失败 | 40 |
| 成功解析并写入 `body_text` | 47 |
| 已归档但仍需 OCR 的正文图片 | 6 |
| 已归档但仍需文档解析的 DOC | 1 |
| v2.2 剩余空正文 | 47 |

40 个失败链接中，10 个返回 HTTP 404，30 个旧会员站链接返回 HTTP 502。失败状态、URL、时间和错误信息均保存在回补清单中。

## 改进幅度

- 空正文由 94 篇降至 47 篇，减少 50%。
- 全库正文非空率由 98.11% 提升到 99.05%。
- 另外6篇正文图片已经归档，虽然尚未转成机器可读文字，但原始内容证据已补齐。

## 新增可追溯字段

v2.2 工作库新增 `body_recovery` 表，记录：

- 原公告 URL；
- 回补 URL；
- HTTP 状态；
- 本地保存路径；
- SHA-256；
- 内容类型；
- 使用的正文选择器；
- 恢复文字数；
- 是否写入 `body_text`；
- 失败或后续处理说明；
- 回补时间。
